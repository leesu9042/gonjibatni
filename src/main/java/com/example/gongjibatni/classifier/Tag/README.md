
# 공지사항 제목을 기반으로 태그를 자동 분류하는 모듈

---

## 1. 무엇을 하는 모듈인가?

공지사항 제목 문자열을 입력받아  
미리 정의된 키워드 기반 정책을 통해  
해당 공지에 적절한 태그들을 자동으로 추출한다.

예:
- "수강신청 일정 안내" → COURSE
- "장학금 신청 공지" → SCHOLARSHIP
- "교환학생 선발 안내" → OVERSEAS

---
## 2. 어떻게 구성되어 있는가?

### 📌 NoticeTag (Enum)

- 각 태그는 여러 키워드를 가진다.
- `matches(String title)` 메서드를 통해 제목 포함 여부를 판단한다.
- 대소문자를 구분하지 않는다.

**책임**
- 태그 추출 로직 정의

---

### 📌 NoticeTagger

- 모든 `NoticeTag`를 순회하며 매칭 여부를 확인
- 매칭된 태그를 `Set`으로 반환
- 중복 태그를 방지

**책임**
- 태그 추출 로직 실행



---

## 📚 What I Learned

### 1. Enum도 로직을 가질 수 있다
- 단순 상수가 아니라 비즈니스 정책을 담는 객체처럼 사용할 수 있음
- `matches()` 로직을 통해 태그 정책을 한 곳에 모을 수 있었음

### 2. 책임 분리의 중요성
- `NoticeTag`는 정책 정의
- `NoticeTagger`는 실행 담당
- 역할을 분리하면 테스트와 유지보수가 쉬워짐

### 3. 단위 테스트의 목적
- 값이 아니라 "정책이 깨지지 않는지"를 검증하는 것
- 키워드 추가/수정 시 테스트가 안전망 역할을 함

### 4. Set을 사용하는 이유
- 동일 태그가 중복으로 추가되는 것을 방지
- 결과의 의도를 명확히 표현
